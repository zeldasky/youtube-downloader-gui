========================================
  YouTube 다운로더 (포터블판)
========================================

■ 실행 방법

  "YouTube 다운로더.exe" 를 더블클릭하세요.

  설치할 것이 아무것도 없습니다.
  파이썬, ffmpeg, Node.js 등을 따로 깔 필요 없이 바로 실행됩니다.


■ 옮기거나 전달할 때

  이 폴더를 통째로 복사하세요. (USB, 압축파일 등)
  폴더 안의 bin, _internal 폴더가 함께 있어야 동작합니다.
  exe 파일 하나만 빼서 옮기면 실행되지 않습니다.

  폴더 위치는 어디든 상관없습니다. (바탕화면, D드라이브, USB 등)


■ 사용 순서

  1. 맨 위 칸에 유튜브 주소를 붙여넣고 [추가] 를 누릅니다.
     - 이미 주소를 복사해 두었다면 [클립보드에서] 버튼이 더 빠릅니다.
     - 주소를 여러 개 넣어두고 한 번에 받을 수 있습니다.

  2. [다운로드 옵션] 에서 고릅니다.
     - 형식 : 비디오(MP4)  또는  오디오(MP3)
     - 품질 : 상 / 중 / 하

  3. [저장 폴더] 에서 [폴더 선택] 을 눌러 받을 위치를 정합니다.
     (한 번 정하면 다음 실행 때도 그대로 유지됩니다)

  4. [다운로드 시작] 을 누릅니다.

  5. 다 받은 뒤 [폴더 열기] 를 누르면 탐색기로 바로 열립니다.


■ 품질 기준

  품질   비디오                    오디오
  ----   ----------------------    --------------------
  상     최대 2160p (4K)           MP3 약 320kbps
  중     최대 1080p (FHD)          MP3 약 192kbps
  하     최대 480p  (SD)           MP3 약 128kbps

  ※ 원본보다 좋은 화질/음질로는 받을 수 없습니다.
     원본이 720p 라면 "상" 을 골라도 720p 로 받습니다.


■ 메뉴

  파일   - 저장 폴더 선택 / 저장 폴더 열기 / 종료
  도구   - 다운로더 실행 파일 지정 / 자동 탐지로 되돌리기 / 버전 확인 /
           업데이트 / 로그 지우기
  도움말 - 정보


■ 문제가 생기면

  - 창 아래쪽 [로그] 칸에 원인이 그대로 표시됩니다.

  - "Video unavailable" : 비공개, 삭제, 지역 제한된 영상입니다.

  - 유튜브가 사양을 바꿔서 갑자기 안 될 때가 있습니다.
    [도구] > [다운로더 업데이트] 를 눌러보세요.

  - "HTTP Error 403: Forbidden" : 받는 도중에 끊긴 것으로, 대개 다운로더가
    오래돼서 생깁니다. [도구] > [다운로더 업데이트] 후 다시 받으세요.
    프로그램을 켜면 로그 맨 위에 다운로더 버전이 나오고, 60일이 넘은
    버전이면 경고가 함께 표시됩니다.

  - 백신이 처음 실행을 막을 수 있습니다. (서명되지 않은 프로그램이라서)
    차단되면 "허용" 을 눌러주세요.


■ 내장된 구성 요소

  bin\yt-dlp.exe    다운로드 담당 (Unlicense / 퍼블릭 도메인)
  bin\ffmpeg.exe    화질 병합, MP3 변환 담당 (LGPL v2.1+)
  bin\ffprobe.exe   미디어 정보 확인 (LGPL v2.1+)
  bin\qjs.exe       QuickJS - 유튜브 추출에 필요한 JS 엔진 (MIT)

  ffmpeg 라이선스 전문은 bin\FFMPEG-LICENSE.txt 를 보세요.
  ffmpeg 소스코드: https://github.com/BtbN/FFmpeg-Builds


■ 설정 파일 위치

  %APPDATA%\YoutubeDownloader\config.json

  (저장 폴더, 품질 설정이 여기에 기록됩니다.
   프로그램 폴더를 지워도 이 파일은 남습니다.)
